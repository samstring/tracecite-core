# 正则资源门禁迁移说明

TraceCite 现在会在内置过滤、分段、预处理和断言路径执行用户正则前，先做有界的结构检查。
本次变更不修改持久化 schema，但收紧了输入行为：超长表达式、嵌套可变重复等已知会触发
灾难性回溯的形态，可能在扫描任何来源前直接抛出 `re.error`。

普通字面量、日期模式、有限重复、可选包装以及无前缀歧义的 alternation 仍然可用。
受门禁影响的调用方，应在不需要正则语义时改用 literal search，或把含歧义的嵌套重复
改写成单层有界表达式。Runtime 断言继续保留原有的“无效正则按字面量处理”回退语义。

该门禁是资源保护措施，并不声称所有通过检查的表达式都具有线性时间复杂度。
自行执行正则的扩展 handler 仍需为自己的输入施加等价边界。
