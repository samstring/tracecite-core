Version: 1.3.0 alpha, aarch64-Darwin-cocoa, macOS 15.7.5

Symptom
=======
Pressing F3 on an ordinary .txt file crashes Double Commander on macOS. The reporter sees the crash for local and remote files, and no doublecmd.err file is produced.

Regression window
=================
Revision 12833 / commit 5c8e18b7f: crashes.
Reporter states the problem started with Revision 12831 and is still present in 12833.
Revision 12796 / commit 731071dae: works; pressing F3 on a normal .txt file does not crash.

Environment
===========
Double Commander 1.3.0 alpha
Lazarus 4.99.0.0
Free Pascal 3.2.2
Platform aarch64-Darwin-cocoa
macOS 15.7.5

Evidence constraints
====================
There is no application crash log in the normal preferences location. The strongest evidence is the tight revision regression window and that the trigger is opening the built-in viewer (F3) for a normal text file on macOS.
